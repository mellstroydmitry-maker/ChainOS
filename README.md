# ChainOS
Mobile OS
Thanks to everyone reading this README. It was created to provide a detailed description of the project known as ChainOS (or by its codename, Blaster).

The goal of the project isn't to create a powerful mobile OS, but rather a solid foundation for other enthusiasts who want to build their own operating systems. Of course, anyone could just take AOSP...

But where's the fun in that?

Certainly not for me!
